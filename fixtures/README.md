# Fixtures

- `audio/`: real, licensed clips (see `audio/LICENSES.md`). Committed.
- `synthetic/`: generated by `tools/make-synthetic-fixtures.mjs` from the engine and playback synth
  (exact ground truth, no licence questions). Git-ignored; `nx run audio-analysis:eval` regenerates them.

## Labelling a real clip

`audio/my-clip.wav` + `audio/my-clip.chords.json`:

```json
{
  "kind": "voice and guitar",
  "bpm": 92,
  "beatsPerBar": 4,
  "chords": [
    { "start": 0.42, "chord": "G" },
    { "start": 3.05, "chord": "Em" }
  ]
}
```

`start` is in seconds; chord names use the engine's vocabulary (G, Em7, D/F#, Bbmaj7…).
Convert other formats first, e.g. `ffmpeg -i clip.mp3 clip.wav`.
